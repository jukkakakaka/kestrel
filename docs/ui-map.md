# 工作台布局与路由地图（v0.4.0）

## 三栏自适应工作台外壳

Kestrel v0.4.0 采用专业金融终端式的**三栏自适应工作台**架构（定义于 `web/templates/base.html` 与 `web/static/css/app.css`）：

1. **左侧可折叠分组导航栏（`aside.app-rail`）**：
   - 桌面默认展开宽度 `220px`，点击底部折叠按钮一键切换为 `64px` 纯线性 SVG 图标栏（状态持久化于 `localStorage['kestrel.rail']`）；当窗口处于 `960px–1220px` 或展开右侧 Copilot 且总宽 `<1400px` 时自动优雅收窄为紧凑图标栏；`<960px` 自动转为毛玻璃遮罩侧滑抽屉（`#mobile-nav-btn` 唤起，支持点击遮罩或 `Esc` 关闭）。
   - 导航按三大分组组织：**核心工作流**（今天 `/`、行情 `/market`、操作建议 `/advice`、交易台账 `/journal`）、**分析与证伪工具**（成本计算 `/cost`、快速模拟 `/sim`、规则 `/rules`）、**系统与常驻状态**（后台盯盘运行状态胶囊直达 `/settings#desktop`、设置 `/settings`、折叠侧栏按钮）。
2. **顶部 56px 毛玻璃工具栏（`header.workspace-bar`）**：
   - 左侧/中部：窄屏导航按钮 + 全局快速股票搜索框（按 `/` 聚焦，支持代码/名称联想直达 `/stock/{market}/{code}` 或 `/stock/{code}`）；
   - 右侧控制区：动态总资产/可用现金胶囊 `#open-calibrate` + 紧邻双态**眼睛隐私按钮 `#toggle-privacy`（快捷键 `Alt+P`）**、`+ 记一笔成交` `#top-fill-btn`、「边做边学」词条开关 `#toggle-learning`、AI 顾问开关 `#toggle-copilot`（`⌘K` / `Ctrl+K`）、**三态主题图标切换器 `#theme-switcher`（太阳浅色 / 月亮深色 / 显示器跟随系统）**、**双语切换胶囊 `#locale-toggle`（地球 SVG + `中 / EN` 联动 `POST /api/locale`）**。
3. **主内容区（`main.workspace-main`）与右侧 380px 炒股 Agent 抽屉（`aside.copilot-drawer`）**：
   - 主区启用 CSS Container Queries（`container: main / inline-size`），展开右侧 `380px` Copilot 抽屉（`<1180px` 自动转为浮层抽屉）或任意拖拽缩放桌面窗口时，指标卡、双栏看板、建议卡与响应式表格（`.table-wrapper[tabindex="0"]`）自动重算列数，零横向溢出、零文字截断。

关键状态联动 API：`POST /api/ui/privacy`（金额隐私持久化）、`GET /api/desktop/status` & `POST /api/desktop/settings`（桌面常驻与开机自启同步）、`POST /api/locale`（双语 Cookie 切换）、`GET /api/rules/drift` & `POST /api/rules/validate`（四关证伪与偏离检测）、`POST /api/copilot/chat`（右侧炒股 Agent 对话）。

## 金额隐私保护契约（`data-privacy` & `data-priv`）

为满足实盘盯盘、投屏分享与截图交流时的隐私安全需求，全站严格区分**个人私密头寸**与**公开市场行情**：

- **根状态控制**：`<html data-privacy="on|off">` 由服务端根据 `ui.privacy` 首屏直出，杜绝客户端脚本延迟导致的金额闪现（FOUC）。
- **遮罩范围**：
  - `[data-priv="money"]`：初始本金、总资产、可用现金、持仓市值、单笔风险金、手续费、浮动/已实现盈亏金额 → 开启隐私后纯 CSS 等宽替换为 `••••••`；
  - `[data-priv="qty"]`：持仓股数、建议股数、已平仓股数 → 开启隐私后替换为 `••••`；
  - `input[data-priv-input="1"]`：引导页本金、设置页本金、成本试算金额输入框 → 未聚焦时自动高斯模糊打码，鼠标点击聚焦编辑时清晰显示。
- **公开保留项**：股票现价、入场/止损/目标价位、涨跌幅 `%`、胜率 `%`、盈亏比、R 倍数及回测统计指标在隐私模式下始终清晰展示，不影响看盘与策略复盘。

## 首页为什么叫「今天」

「看板」暗示复杂图表，「行情」只是报价列表。用户每天打开终端真正要回答的是**「我现在该干嘛」**，因此 `/` 首页按紧急度排列待办：跌破止损（立刻离场）、接近止损、涨至 `+1R`/`+2R`（上移保护性止损）、建议即将过期、缺少现价，以及明确的「今天不用动手」。完整报价表独立于 `/market`。

## 成交记录的三个统一入口

1. **手机回执页 `/r/{code}`** — 收到推送后在手机打开，填入真实成交价与成交股数一键入账。
2. **建议卡「按实际成交录入」** — 唤起全局成交弹窗 `#fill-modal`，自动预填建议价、建议股数、止损与目标，修改真实成交价量时实时预演滑点偏差与风险变化。
3. **顶栏 / 台账「+ 记一笔成交」与交割单导入** — 支持手工记入任意市场买卖或直接粘贴券商导出的交割单表格批量解析。

三个入口统一调用 `services/execution.py`，确保整手/科创板 `200+1` 校验、A 股 `T+1` 卖出拦截、FIFO 分批平仓、买费分摊、动态现金扣减/回笼与 What-if 偏差归因只有唯一一套权威实现。

相同录入请求重试时返回原结果。新增部分成交须打开新的表单。建议过期后可从建议历史补录。扫描市场的选择只影响行情、候选池和操作建议。台账与持仓提醒继续覆盖已记账的标的。

「边做边学」是总开关，控制建议解释、复盘提示和模拟页练习。开启后可以在设置中独立关闭术语标注。常规券商操作和记账入口始终可用。
