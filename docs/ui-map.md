# UI map

| Route | Nav | Purpose |
|---|---|---|
| `/` | 今天 | 待办：持仓风险、待处理建议、自选摘要。首次启动会跳到 `/welcome` |
| `/welcome` | — | 三步引导：本金与单笔风险、市场、周期。每项都写进真实设置 |
| `/market` | 行情 | 实时行情、开市状态、来源链接 |
| `/stock/{market}/{code}` | — | 个股：60 日走势、指标、当前建议、持仓与浮盈 |
| `/advice` | 操作建议 | 唯一产生建议的地方；引擎由设置决定，卡片标注来源与周期 |
| `/journal` | 交易台账 | 持仓（现价 / 浮盈 / 距止损）、已平仓、执行质量、成交单导入 |
| `/cost` | 成本计算 | 来回费用、保本价、可编辑的券商套餐 |
| `/sim` | 快速模拟 | 检验规则在历史上的表现，可按日线 / 周线 / 月线分别重放 |
| `/rules` | 规则 | 规则列表、逐折实测、编辑器；验证可按周期分开跑 |
| `/settings` | 设置 | 通用 / 市场与选股 / 数据源 / 分析引擎 / 推送 / 备份 / 术语库 / 关于（版本与更新） |
| `/r/{code}` | — | 手机上的回执页：填真实成交价与数量，直接写进台账 |

旧路径重定向：`/scan` → `/advice`，`/fees` → `/cost`，`/backtest` → `/sim`。

## 首页为什么叫「今天」

「看板」暗示决策，「行情」只是表格。用户早上打开工具真正要回答的是
「我该干嘛」，所以首页放待办：跌破止损（最急）、接近止损、到达目标、
建议快过期、没有现价、以及「今天不用动手」。行情表降级成右上角一张小卡片，
完整版在 `/market`。

## 页面随引擎变化

引擎是全局开关，页面会说明自己在这个开关下的角色：

- **`/advice`** — 副标题显示 `AI 决策 · <模型>` 或 `规则计算`；按钮文字跟着变；
  大模型模式下横幅还会显示今天已用多少次调用。
- **`/rules`** — AI 模式下提示「规则不直接参与选股，但仍为 AI 提供已验证路径的参考」。
- **`/sim`** — AI 模式下提示「本页不参与选股，只用于检验规则是否有用」。

## 周期（短线 / 中线 / 长线）

`trade.horizon` 决定扫描读哪种 K 线、回测持有多久、计划活多久。

- **`/advice`** 顶部一张「交易周期」卡片：当前用哪档、为什么、评分，以及三个按钮
  加一个「自动判断」。选自动时每次扫描前重算；手动固定后不再咨询建议器。
- **`/sim`** 表单多一个周期下拉，回测按所选 K 线重放，历史记录里带周期列。
- **`/rules`** 验证按钮按所选周期跑，每条规则头部显示它在各周期上的最近判定。
- **`/settings`** 同一开关也在「扫描」一节，便于一次性配置。

长线走月线并标 **Beta**：它只用得上量价，没有基本面数据，样本也最少。

## 成交记录的三个入口

1. **回执页 `/r/{code}`** — 手机上打开，填实际价格和数量，一键写进台账。
2. **建议卡「我已经买了」** — 打开和台账页同一个记账弹窗，预填建议的价格、数量、
   止损和目标，用户只改真实成交的那几个数。
3. **台账「记一笔成交」** — 同一个弹窗。代码或名称填一个就够：市场从代码形状推、
   名称从库里查、手续费按券商套餐算、止损目标用缓存 K 线给建议，全部可改。
   同一个分页里还有「导入成交单」：粘贴券商导出的表格，按表头识别列，顺序不限。

三者走同一个 `services/execution.record()`，因此整手校验、FIFO 平仓、
偏差计算、建议状态更新只有一份实现。港股碎股和美股小数股也走这里：
A 股强制整手，港股不足一手、美股 0.0001 股都照实记账。
