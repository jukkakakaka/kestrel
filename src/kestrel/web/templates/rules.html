规则怎么写

一条规则就是「所有条件都满足才进场」。score 里的 bonus 只在条件成立时加分， 用来排序——分高的排前面，但不会改变「是否进场」。 

{
  "code": "my_rule",
  "name": "我的规则",
  "conditions": [
    {"left": "ma_stack", "op": "is_true"},
    {"left": "dist_sma20", "op": "between", "value": [-2, 0.5]},
    {"left": "rsi14", "op": "between", "value": [40, 60]}
  ],
  "score": {
    "base": 0.45,
    "bonus": [
      {"when": {"left": "vol_ratio", "op": "<", "right": 1.1}, "add": 0.15}
    ]
  },
  "stop":   {"field": "low20"},
  "target": {"field": "high20"}
}

操作符：> >= < <= between is_true is_false。 right 既可以写数字，也可以写另一个指标名（比如 "high20"）， 表示两者比较。
